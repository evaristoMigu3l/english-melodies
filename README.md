# Sing With Lyrics

English learning webapp that helps students improve pronunciation through music.

## Features

- Original lyrics display
- Pronunciation transcripts aligned below each word
- Integrated music player
- Color-coded text for easy distinction

## Setup

```bash
npm install
npm run dev
```

## Deployment

Deploy to Vercel:
```bash
npm run build
vercel deploy
```

## Usage

1. Add your audio file to the `public` folder
2. Update the lyrics array in `App.jsx` with your song's lyrics and pronunciations
3. Run the development server

See PROJECT.md for detailed documentation.
